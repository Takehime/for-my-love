# Тебе, моя любимая ♡

Небольшой романтичный сайт-письмо. Он полностью статичный: не нужен сервер, база данных, Node.js или сборка. Подходит для GitHub Pages и хорошо работает на телефоне.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub, например `for-my-love`. Для максимально простой настройки можно сделать его публичным.
2. Загрузи **все четыре файла сайта** (`index.html`, `style.css`, `script.js`, `favicon.svg`) и этот `README.md` в корень репозитория. Можно просто распаковать ZIP и перетащить файлы в интерфейс GitHub.
3. Открой в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажми **Save**.
5. Подожди, пока GitHub Pages опубликует сайт. Адрес появится в разделе Pages и будет примерно таким: `https://ТВОЙ-АККАУНТ.github.io/for-my-love/`.
6. Отправь ей ссылку. Можно сохранить её в закладки телефона или добавить на главный экран.

## Как персонализировать сайт

В начале `script.js` есть блок `SETTINGS`:

```js
const SETTINGS = {
  relationshipStart: '2026-03-29',
  herName: '',
  signature: 'Твой человек'
};
```

- `relationshipStart` — дата начала отношений. Уже установлена на **29 марта 2026 года**.
- `herName` — имя девушки. Например, `herName: 'Аня'`. Можно оставить пустым.
- `signature` — подпись. При желании замени её на своё имя или привычное обращение.

Весь текст письма находится в `index.html`, а короткие послания для разных настроений — в `script.js`. Их можно переписать на ваши личные шутки, любимые обращения и воспоминания.

## Важно о приватности

GitHub Pages — публичный статический хостинг. Любой, у кого есть ссылка на публичный репозиторий или сайт, потенциально сможет посмотреть его содержимое. Не добавляй туда личные данные, которые не хочешь публиковать, или фотографии без согласия девушки.

## Примечание

Для подключения красивых шрифтов сайт пытается загрузить Google Fonts; если они недоступны, автоматически используются системные шрифты. Остальные эффекты и интерактивность работают без внешних сервисов.


## Мобильная адаптация

Сайт поддерживает узкие экраны от 320 px, телефоны в портретной и альбомной ориентации, области вырезов/домашнего индикатора и увеличенные сенсорные зоны. На маленьких экранах карточки и кнопки перестраиваются в одну колонку, а письма и всплывающие окна можно прокручивать без выхода за пределы экрана.
